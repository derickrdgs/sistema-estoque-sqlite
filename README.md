# 🗄️ Sistema de Estoque com SQLite — Java

Sistema de controle de estoque desenvolvido em **Java** com persistência de dados utilizando **SQLite** e **JDBC**.

A aplicação representa um passo além de um sistema de estoque em memória, permitindo armazenar os produtos em um banco de dados local.

## ✨ Funcionalidades

- ➕ Cadastro de produtos
- 📋 Listagem de produtos
- 💾 Persistência dos dados em SQLite
- 🔌 Integração entre Java e banco de dados através de JDBC

## 🧠 Conceitos aplicados

- Java
- Banco de dados SQLite
- JDBC
- Persistência de dados
- Operações básicas de acesso a dados

## 🎯 Objetivo

Praticar a integração entre uma aplicação Java e um banco de dados relacional, trabalhando com **persistência de informações** e preparando a base para projetos mais completos.

## 🚀 Como executar

1. Instale o **JDK**.
2. Clone este repositório.
3. Abra o projeto na sua IDE.
4. Verifique se a dependência/driver do SQLite está configurada.
5. Execute a classe principal da aplicação.
